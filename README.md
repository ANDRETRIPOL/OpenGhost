# OpenGhost

OpenGhost is a desktop agent for Windows. The agent engine and the rendering engine are written from scratch.

The agent runs commands, reads and edits files, and keeps a project in git. When an answer can be shown, the app draws a chart or a diagram instead of leaving it as text only. Diagrams can be edited in place.

A built-in browser sits beside the chat. The agent opens pages and drives them with its own cursor. It sees the screen, clicks, and types. Sign-ins made in that browser stay on the computer and are available in later chats.

Mini chat is a small window for a side question. It is not saved.

The agent has three permission modes. Ask waits for approval. Auto works inside the project folder and asks before risky steps. Full access does not ask.
