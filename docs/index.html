Day-to-day features

Follow-ups, search,
and a few useful extras.

Keep a follow-up separate, find an old conversation, and check your usage without leaving the app.

Follow up in Mini chat.

Select a passage and open Mini chat over the conversation. Drag it, resize it, and keep writing behind it. Its own agent uses the current chat as context, works in a separate browser tab, and coordinates with the main agent so they do not change the same file. Close it during a task and the work continues.

Explore Mini chat

Find where you left off.

Click the magnifier or press Ctrl+K to search your chats. Results are grouped under their folders, so a useful conversation does not disappear into a long list. New chats can start without a project; OpenGhost gives them a folder of their own for the files the agent creates.

See chat search

Know what a chat costs.

Open Chat stats from the plus menu to see spending, tokens for each reply, each model’s share, cache usage, and context fullness. Compact chat frees space in a long conversation; OpenGhost also compacts automatically before the model’s context window fills.

Inside Chat stats

Your instructions, always there.

In Settings → General, write how you want answers and what the agent should know. Add files it should always have at hand, such as notes, a style guide, or a CV. Every chat receives them, even after compaction. For a project’s own rules, put an AGENTS.md in its folder.

Set your preferences

Make the space yours.

Choose light, dark, or your system’s theme and adjust the interface size. Pick your message colour and the chat background separately for each theme. Until you choose, the original themes stay as they are. The app opens with its ghost flying through the mist.

Explore Appearance

See the actual thing.

When a picture says more, the agent searches for photos and videos itself. Pictures arrive in a stack you can leaf through, with a link to their source. Videos become preview cards with a name and length, opening in your browser. Live drawings have their own forms for recipes, meals, documents, matches, languages, PC builds, settings, and trips.

Source code

Not assembled.
Written from scratch.

Its own agent loop, tools, and approval cards. Its own browser tooling and drawing engine. Its own streaming Markdown renderer, code highlighting, and math. Every interface control, its motion, and its glass is plain JavaScript and CSS.

No UI framework, Markdown library, Mermaid, chart library, or agent framework. Built on Electron and Anthropic’s official SDK. The source is there for you to read, build, and understand.

Build it yourself
# A desktop agent. From the source.
$ git clone https://github.com/ANDRETRIPOL/OpenGhost.git
$ cd OpenGhost
$ npm ci
$ npm start
Node.js 22+·Runs on macOS, Windows, and Linux

Source code is MIT-licensed. The name, logo, animations, and app design have separate terms.

Build a Windows installer

After npm ci, run npm run dist on Windows. The installer is written to dist/OpenGhost-<version>-Setup.exe.

Build a macOS disk image

After npm ci, run npm run dist:mac on macOS. The disk image is written to dist/OpenGhost-<version>-mac.dmg.

Build a Linux archive

After npm ci, run npm run dist:linux on Linux. The archive is written to dist/OpenGhost-<version>-linux.tar.gz.

Build with GitHub Actions instead

No Mac or Linux machine available? In your GitHub fork, enable Actions, open the Build workflow, and choose Run workflow. Download the files from that run’s page. See the build documentation. These commands build the desktop app, not this static website.

Good questions

A few things
worth knowing.

Still curious? The repository has the full story.

Read the documentation
Is OpenGhost really free?

Yes. The app is free to download and use. You bring your own ChatGPT account or API credentials; provider subscriptions, limits, and API usage costs still apply. You can support development through GitHub Sponsors.

Will it ask me questions before it starts?

Only when a request can go several really different ways. Then a small deck of cards appears over the message field: pick a choice, or write your own answer. Clear requests are simply done.

Does it run AI models locally?

OpenGhost is a desktop app, not a bundled local model. It connects to ChatGPT, OpenAI, Claude, DeepSeek, and OpenRouter. Your keys and sign-ins stay encrypted on your machine, but prompts and relevant context are sent to the provider you choose.

What can it do on my computer?

It can run commands, read and change files, work with git, search the web, and use its shared browser. Ask mode waits for approval; Auto works inside the project and asks before risky steps; Full access does not ask. Operating-system permissions still apply. Start with Ask while you get familiar with it.

How are my credentials and chats protected?

Keys and provider sign-ins are stored on your computer, encrypted by the operating system. You can also lock an individual chat with a password: its content is encrypted locally, not merely hidden behind a lock screen. This does not make model requests offline; prompts and relevant context still go to the provider you select.

What is the difference between Quick chat and Mini chat?

Quick chat opens over your desktop with Alt+Space or your own shortcut. It has its own model and effort and can search the web, but it has no built-in browser. Use its header arrows to open the conversation in the main app for browser work. Mini chat opens from a selected passage inside a conversation. It uses that chat as context, floats above it, and has its own agent and browser tab. Both can keep working when their small window is closed.

Why does Quick chat’s shortcut not work?

Alt+Space may already belong to the operating system or another app. Settings → General shows a shortcut conflict; choose another combination there. On Linux, Wayland may not allow an app a global shortcut at all, and starting OpenGhost with the computer is configured through your desktop’s own settings.

Why does the app stay running after I close it?

With Quick chat enabled, closing the main window keeps OpenGhost in the tray so the shortcut still works. Quit from the tray icon, or turn Quick chat off in Settings → General. On Linux desktops without a tray, such as GNOME out of the box, start OpenGhost again to bring the window back; turn Quick chat off before closing the window to quit.

Why does macOS still ask for permissions?

Ask, Auto, and Full access govern the agent, not macOS. The system separately controls access to Desktop, Documents, Downloads, and other apps. Approve the access you need, or use the Full Disk Access button in Settings → General to open the system setting. The app’s ad hoc signature lets macOS remember approvals for each build, but a new update needs approval again. It is not an Apple Developer ID signature, so first launch also requires right-click → Open or Privacy & Security → Open Anyway.

Do I need a project folder to start?

No. Start a new chat and ask your question. It appears under Chats with a folder of its own for files the agent makes. When you work on a project, the conversation lives in that project’s folder. A project can provide its own instructions through an AGENTS.md file.

How do memory and saved instructions differ?

Memory keeps short, editable records about you across chats, changing an existing record when something changes. You can add, edit, remove, or disable it in Settings → Memory. General settings are the instructions and reference files you explicitly supply for every chat. Those instructions and files remain available after a conversation is compacted.

What happens when a conversation gets long?

The plus menu’s Chat stats shows how full the context is, along with spending, tokens per reply, model share, and cache usage. Compact chat frees context, and the app also compacts automatically before the model’s window fills. Your saved General instructions and reference files are kept available through compaction.

Can I build or modify it myself?

Yes, the source code is MIT-licensed. You need Node.js 22 or newer to build it. The OpenGhost name, logo, animations, and application design are excluded from that license. A published or distributed modified app must have its own name, logo, animations, and visual design. The excluded materials may not be used commercially; uses beyond the license’s allowances need the author’s written permission. Run the official app or an unchanged personal source build under the stated terms. See the installer commands above and read the full license before publishing.

Where do I report a bug or share an idea?

Open an issue on GitHub with your operating system, OpenGhost version, and steps to reproduce it. You can also join the Discord community.
